# QRGUARD "Airlock" design reference

Static mockups (inline-styled HTML) of the new website look. They are a VISUAL
REFERENCE ONLY: do not copy their markup into the app. The <x-dc>, <helmet> and
<script type="text/x-dc"> tags are from the mockup tool and should be ignored.

- Airlock.html       – Check page, dark mode (main screen)
- AirlockLight.html  – Same page, light mode
- Reality.html       – Result page: "Claims vs reality" split view (dark)
- Result.html        – Older light result page; reuse its "Link X-ray",
                       "Why <score>" breakdown, threat sources and redirect chain
- Pass.html          – Shareable "Inspection pass" card (dark)
- PassLight.html     – Same card, light mode

Placeholders in [square brackets] stand for real data from the analysis API.
